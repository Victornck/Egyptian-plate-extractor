# Proveniência das imagens

Fotografias positivas: `imagens/carros/img_001.jpg` até `img_050.jpg`, preservadas sem alteração do [repositório original](https://github.com/Ahm3d0x/Automatic-License-Plate-Recognition-Classical-Image-Processing-/tree/612bcd8b09aace4181b8737dc0e739823902db03/dataset). Commit: `612bcd8b09aace4181b8737dc0e739823902db03`. A versão 1.0.0 usou `img_001` a `img_020`; a versão 1.1.0 incluiu `img_021` a `img_050` do mesmo commit. Licença MIT do repositório preservada em `LICENCA-DATASET.txt`. Metadados: `fontes-imagens.json`. Este projeto usa imagens desse conjunto para teste; não usa seu código de reconhecimento.

Fotografias negativas: arquivos originais do [scikit-image v0.19.3](https://github.com/scikit-image/scikit-image/tree/v0.19.3/skimage/data). Atribuições conforme a [documentação das amostras](https://github.com/scikit-image/scikit-image/blob/v0.19.3/skimage/data/_fetchers.py):

`LICENCA-SKIMAGE.txt` preserva as informações de licença do projeto fornecedor. `imagens-sha256.txt` permite verificar os arquivos entregues. As derivações de iluminação, dimensão, rotação e ausência de cor são identificadas como transformações nos testes e na validação.
